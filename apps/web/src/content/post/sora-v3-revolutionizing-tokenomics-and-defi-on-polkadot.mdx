The Multi-EVM Bridge marks a big step forward. Its code is under review for a security audit. This bridge connects different blockchains that use the Ethereum Virtual Machine (EVM), making them work together smoothly.

This innovation allows tokens to move freely between EVM-based chains and SORA V3's network. The team is also working on a fee structure to make transactions cost-effective for users.

## DeFi Innovations in SORA V3

SORA V3 brings fresh ideas to the DeFi world. It introduces tools that enhance liquidity and connectivity, making trading smoother for everyone.

### Aggregate Liquidity Technology

Aggregate Liquidity Technology (ALT) optimizes liquidity sourcing in SORA V3. ALT reduces transaction fees and computational costs. Work on weights is complete, and unit tests are ongoing.

This technology also finalizes liquidity source limits, response formats, and upgrade testing.

### Substrate Bridge Deployment

SORA V3 introduces the Substrate Bridge to connect with the Liberland chain. This bridge is now in production, allowing trading of Liberland Dollar (LLD) and Liberland Merit (LLM).

The HASHI Substrate Bridge is in the testnet phase, showing progress.

This bridge adapts for non-parachain Substrate-based chains by sovereign countries. It boosts liquidity and enhances seamless transactions within the SORA ecosystem. Users benefit from improved infrastructure linking global financial systems through [Polkadot's technology](https://soranauts.com/polkadot-architecture-guide).
