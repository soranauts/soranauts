## What Are NFTs?

**NFT** stands for **Non-Fungible Token** — a digital proof of ownership stored on a blockchain.  
Unlike **fungible tokens** such as **XOR** or ETH, each **NFT** is **one-of-a-kind**, with its own identity, properties, and provenance.  

Common use cases include:
- **Digital art**, collectibles, or in-game items  
- **Music**, photography, and media rights  
- **Real-world assets** like deeds or certifications  
- **Cross-chain** assets that move between networks  

Each NFT is transparent and tamper-proof, secured by **Hyperledger Iroha’s** blockchain framework for **interoperability** and reliability within the **SORA ecosystem**.

---

## How NFTs Differ from Regular Tokens

Traditional **tokens** like **XOR** or USDT are **fungible**, meaning each unit is identical and interchangeable.  
**NFTs** are **non-fungible**, meaning:
- Each has unique **metadata** and provenance  
- **Ownership history** is recorded permanently  
- Value varies by **rarity**, demand, or creator significance  

| **Fungible Tokens** | **Non-Fungible Tokens (NFTs)** |
|-------------------|--------------------------------|
| Interchangeable (1 XOR = 1 XOR) | Unique (each NFT is distinct) |
| Equal value units | Variable value |
| Used for payments | Used for ownership, identity, or collectibles |
| **XOR**, USDT, ETH examples | Art, domains, game items |
| Divisible | Usually indivisible |
| No ownership history | Full **provenance** tracking |

**Fungible tokens represent money — NFTs represent things.**

## The Technology Behind NFTs

**NFTs** rely on **smart contracts** that define how ownership is tracked and transferred.  
These contracts store **metadata** and interact with decentralized systems like **IPFS** for content storage.

### Key Components

- **Token Standards:** Similar to ERC-721 or ERC-1155 equivalents  
- **Metadata:** Describes the asset (image, creator, etc.) stored on **IPFS**  
- **Immutable Records:** Verify authenticity and history  
- **Cross-chain Bridges:** Allow NFTs to move between blockchain networks  

### IPFS and Decentralized Storage

**IPFS (InterPlanetary File System)** enables:
- **Decentralized storage** for NFT assets  
- **Permanent, censorship-resistant links**  
- **Resilient access** even if servers fail  

**SORA’s** architecture extends these standards into a **DeFi context**, enabling NFTs to interact with financial protocols, liquidity systems, and cross-network assets.
