## Archive Philosophy

This archive preserves **landmark events only**—not every Medium post or minor update. Each entry represents a significant shift in SORA's trajectory:

- **Network launches** — Major version releases
- **Ecosystem milestones** — Parachain wins, product launches
- **Technology shifts** — Platform migrations, new capabilities
- **Annual reviews** — Yearly summaries of progress

For comprehensive update history, see the [SORA Medium blog](https://sora-xor.medium.com).
