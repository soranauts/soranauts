# Polkaswap 2.0 Launch

**Published:** June 2023

In mid-2023, the SORA ecosystem unveiled **Polkaswap 2.0** — a major upgrade to the cross-chain liquidity aggregator DEX. This release significantly enhanced trading capabilities, improved capital efficiency, and laid the groundwork for future innovations.

## Key Improvements

<CardGrid>
  <Card title="Enhanced Routing" icon="random">
    Smarter path-finding across multiple liquidity sources.
  </Card>
  <Card title="Order Book Integration" icon="document">
    Limit orders alongside AMM swaps.
  </Card>
  <Card title="Improved UX" icon="star">
    Redesigned interface for easier trading.
  </Card>
  <Card title="Better Performance" icon="rocket">

## What Changed

### Smart Routing 2.0

The upgraded [smart routing](/glossary/smart-routing) algorithm:

| Aspect | Polkaswap 1.x | Polkaswap 2.0 |
|--------|---------------|---------------|
| Liquidity Sources | Limited | Multiple |
| Path Optimization | Basic | Advanced |
| Split Orders | No | Yes |
| Price Discovery | Simple | Multi-source |

### Order Types

New order capabilities:

- **Market orders** — Instant execution at best price
- **Limit orders** — Set your target price
- **Partial fills** — Execute as liquidity allows

### Liquidity Aggregation

[Liquidity aggregation](/glossary/liquidity-aggregation) improvements:

- More sources integrated
- Better price discovery
- Reduced slippage
- Higher capital efficiency
