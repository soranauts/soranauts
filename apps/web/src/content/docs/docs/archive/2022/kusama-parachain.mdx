# Kusama Parachain Victory

**Published:** April 2022

## The Auction Process

### How Parachain Auctions Work

Kusama uses a candle auction mechanism:

1. **Bidding period** — Projects bid KSM for slots
2. **Candle phase** — Random ending point determined
3. **Winner selection** — Highest bid at random end wins
4. **Lease period** — Winner operates as parachain

### SORA's Campaign

The community rallied to support SORA:

- **Crowdloan** contributions from supporters
- **KSM bonding** for the lease period
- **Community mobilization** across channels
- **Competitive bidding** against other projects

<Aside type="note">
Crowdloan contributors received rewards for their support, aligning community incentives with network success.
</Aside>

## Technical Implementation

### Integration Steps

1. **Parachain runtime** deployed to Kusama
2. **Collators** set up for block production
3. **XCM channels** opened with other parachains
4. **Bridge configurations** updated

### Cross-Chain Features

Enabled capabilities:

- Asset transfers to/from other parachains
- Cross-chain DEX integration
- Shared liquidity pools
- Multi-chain DeFi strategies
