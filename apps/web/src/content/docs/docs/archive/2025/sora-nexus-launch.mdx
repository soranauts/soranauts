# SORA Nexus Announcement

**Published:** November 30, 2025

In late 2025, the SORA team unveiled **SORA Nexus** — the next-generation blockchain network that represents the most significant architectural evolution since SORA's inception. Built on [Hyperledger Iroha 3](/glossary/iroha3), Nexus introduces breakthrough technologies designed to position SORA as the backbone for global digital finance.

## The Vision

[SORA Nexus](/glossary/sora-v3) is not merely an upgrade—it's a fundamental reimagining of what the SORA network can be:

> "SORA Nexus creates a supranational platform where CBDCs and digital assets operate free from political and economic instability."

## Technical Highlights

### From Substrate to Iroha 3

The decision to migrate from [Substrate](/glossary/substrate) to [Hyperledger Iroha 3](/glossary/hyperledger-iroha) reflects SORA's evolving requirements:

| Aspect | SORA v2 (Substrate) | SORA Nexus (Iroha 3) |
|--------|---------------------|---------------------|
| Finality | 12-60 seconds | Sub-second |
| Smart Contracts | Ink! WASM | ISI + WASM |
| Consensus | BABE/GRANDPA | Sumeragi BFT |
| Enterprise Focus | Limited | Native |
| CBDC Support | Workarounds | Built-in |

### Sumeragi Consensus Evolution

The enhanced [Sumeragi](/glossary/sumeragi) consensus algorithm provides:

- **Deterministic finality** — No block reorganizations
- **Byzantine fault tolerance** — Operates with up to 1/3 malicious nodes
- **High throughput** — Thousands of transactions per second
- **Low latency** — Block times under 2 seconds

### Data Spaces Architecture

One of Nexus's most innovative features is the **Data Spaces** concept:

```
┌─────────────────────────────────────────────────────────┐
│                    SORA Nexus Hub                        │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐     │
│  │   DeFi      │  │   CBDC      │  │  Enterprise │     │
│  │ Data Space  │  │ Data Space  │  │ Data Space  │     │
│  └─────────────┘  └─────────────┘  └─────────────┘     │
└─────────────────────────────────────────────────────────┘
```

Each Data Space can have:
- Custom governance rules
- Specialized validators
- Domain-specific logic
- Controlled interoperability

## Economic Implications

### XOR in the Nexus Era

[XOR](/glossary/xor) remains the native utility token, with enhanced roles:

- **Transaction fees** across all Data Spaces
- **Staking** for validator participation
- **Governance** through SORA Parliament
- **Bridge collateral** for cross-chain operations

### CBDC Integration

Nexus positions SORA as infrastructure for Central Bank Digital Currencies:

- National banks can deploy sovereign Data Spaces
- Assets remain de-correlated from political instability
- Global settlement layer connects isolated economies
- [SORAMITSU](/glossary/soramitsu)'s CBDC expertise embedded

The [SORA Parliament](/glossary/sora-parliament) receives significant upgrades:

### Iroha Special Instructions

Governance logic implemented via [ISI](/glossary/iroha-special-instructions):
