# SORA v2 Launch

**Published:** April 2021

In early 2021, [SORAMITSU](/glossary/soramitsu) launched **SORA v2** — the [Substrate](/glossary/substrate)-based mainnet that would become the foundation for the modern SORA ecosystem. This release introduced [XOR](/glossary/xor), [VAL](/glossary/val), [PSWAP](/glossary/pswap) tokens and the [Polkaswap](/glossary/polkaswap) DEX, establishing SORA as a significant player in decentralized finance.

## From v1 to v2

### SORA v1 (Legacy)

The original SORA network:

- [Hyperledger Iroha](/glossary/hyperledger-iroha) based
- Limited programmability
- Focused on asset management
- Enterprise-oriented

### SORA v2 (New Era)

The upgraded network:

| Aspect | SORA v1 | SORA v2 |
|--------|---------|---------|
| Framework | Iroha | Substrate |
| Smart Contracts | Limited | Full WASM |
| DeFi | Basic | Full Polkaswap |
| Ecosystem | Standalone | Polkadot-ready |

<Aside type="note">
The v1 → v2 transition demonstrated SORA's ability to evolve architecturally while maintaining community continuity.
</Aside>

## Token Launch

### XOR (Network Token)

[XOR](/glossary/xor) debuted as the native utility token:

- **Elastic supply** via [Token Bonding Curve](/glossary/token-bonding-curve)
- **Transaction fees** across the network
- **Governance participation** rights
- **DEX trading** base pair

### VAL (Validator Token)

[VAL](/glossary/val) launched for network security:

- **Validator rewards** distribution
- **Deflationary** burn mechanism
- **Fee burning** from transactions

### PSWAP (DEX Token)

[PSWAP](/glossary/pswap) incentivized liquidity:

- **LP rewards** for liquidity providers
- **Buyback-and-burn** from trading fees
- **Strategic incentives** for ecosystem growth

---

## Polkaswap Launch

The [Polkaswap](/glossary/polkaswap) DEX launched alongside v2:

### Core Features

- **Liquidity aggregation** from multiple sources
- **Smart routing** for optimal prices
- **XYK pools** for trading pairs
- **Cross-chain ready** architecture

### Initial Pairs

First trading pairs included:

- XOR/VAL
- XOR/PSWAP
- XOR/ETH (via bridge)
- Additional pairs over time

## Technical Foundation

### Substrate Choice

Why [Substrate](/glossary/substrate)?

| Benefit | Impact |
|---------|--------|
| Modularity | Custom pallets for SORA needs |
| Upgradability | Forkless runtime updates |
| Polkadot Ready | Future parachain capability |
| Developer Tools | Rich ecosystem support |

### Architecture Highlights

- **Pallet-based** modular design
- **WASM runtime** for upgrades
- **Nominated PoS** consensus
- **Cross-chain** infrastructure ready

## Historical Significance

SORA v2 established foundations that persist today:

1. **Tokenomics** — XOR, VAL, PSWAP model still active
2. **Polkaswap** — Continues as primary DEX
3. **Governance** — Parliament builds on v2 foundation
4. **Community** — Core community formed during v2 era
