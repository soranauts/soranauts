# TONSWAP

[TONSWAP](/glossary/tonswap) is a next-generation decentralized exchange (DEX) and launchpad built on [The Open Network (TON)](https://ton.org) blockchain. It brings the SORA ecosystem's innovative DeFi technology to the TON community with ultra-fast trades, near-zero fees, and seamless Telegram integration.

## The SORA-TON Connection

TONSWAP creates a powerful bridge between two ecosystems:

### For TON Users

- Access to SORA's DeFi infrastructure
- Trade XOR, VAL, PSWAP on TON
- Benefit from Polkaswap technology

### For SORA Users

- Access TON-native tokens
- Telegram wallet integration
- Massive user base exposure

### XOR Buyback Mechanism

A key feature of TONSWAP is its connection to the SORA economy:

```
10% of all TONSWAP trading fees → Buy back and burn XOR
```

This mechanism:

- Creates sustained demand for [XOR](/glossary/xor)
- Reduces XOR circulating supply
- Aligns TON ecosystem activity with SORA
- Benefits both communities

<Aside type="note">
The XOR buyback is automatic and transparent, executed through smart contract logic.
</Aside>

## Key Features

### Concentrated Liquidity (CLMM)

TONSWAP uses concentrated liquidity market maker (CLMM) technology:

| Traditional AMM | CLMM |
|-----------------|------|
| Liquidity spread across all prices | Liquidity concentrated in ranges |
| Lower capital efficiency | Higher capital efficiency |
| More slippage | Less slippage |
| Lower LP returns | Higher LP returns |

### Launchpad

TONSWAP includes a token launchpad for new projects:

- Fair launch mechanisms
- Community participation
- Vetting process for quality
- Early access for liquidity providers

### Telegram Integration

Native support for Telegram users:

- Trade directly from Telegram
- Wallet in your messenger
- Social trading features
- Instant notifications

## Trading on TONSWAP

### Supported Assets

- **TON** — Native network token
- **Jettons** — TON-native tokens
- **SORA tokens** — XOR, VAL, PSWAP (bridged)
- **Stablecoins** — USDT, USDC (TON versions)

### How to Trade

1. Connect your TON wallet (or Telegram wallet)
2. Select tokens to swap
3. Enter amount
4. Review quote and fees
5. Confirm transaction
6. Receive tokens instantly
