# Soranauts Project Instructions

## Quick Reference
- Read `MASTER_GUARDRAILS.md` for full project rules
- Read `docs/ARTICLE_EDIT_PLAN_TEMPLATE.md` for article editing standards
- Check `docs/claude-reference/LINK_INVENTORY.md` for valid internal links

## Content-Only Changes (Articles, Glossary)
When modifying ONLY files in `apps/web/src/content/`:
- Push directly to main
- No feature branch needed
- No confirmation needed
- Commit prefix: "content:"

## Code Changes (Everything Else)
- Create feature branch
- Get approval before pushing
- Run `pnpm build` to verify
