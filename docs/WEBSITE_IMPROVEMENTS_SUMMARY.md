# Soranauts Website Improvements
## September – December 2025

A summary of all the exciting updates and new features added to Soranauts over the last three months. This guide is written for readers and community members — no technical jargon required!

---

## 🎉 Major Highlights

### The Glossary Got a Complete Makeover
The SORA Glossary has been transformed into a powerful learning tool. What started as a simple list of terms is now a **369-term encyclopedia** of everything SORA. You can now:

- **Instantly preview any term** without leaving the page you're on — just click a term and a panel slides in from the side
- **Search faster than ever** with the new ⌘K (Command+K) keyboard shortcut
- **Filter by category** to find exactly what you're looking for (Economics, Technology, DeFi, Governance, and more)
- **Share specific terms** with friends using direct links
- **See related terms** at a glance to discover connected concepts

### New SORA Codex Documentation
We launched **24 brand new documentation pages** covering:
- SORA fundamentals (what it is, how it works, why it matters)
- Products (Polkaswap, Kensetsu, TONSWAP, Fearless Wallet)
- Technical specifications for developers
- Historical archive of the ecosystem's evolution

### Explorer V3: Your New Home for Discovery
The Explorer is now organized into **six themed areas**:
- **Ecosystem** — Understanding SORA, Polkaswap, wallets
- **DeFi** — Trading, liquidity, yield farming
- **Economics** — Tokens, tokenomics, monetary policy  
- **Governance** — Voting, proposals, community decisions
- **Technology** — How it's built (Substrate, bridges, smart contracts)
- **Network** — Validators, consensus, security

Each area includes **curated learning paths** to guide you from beginner to advanced topics step by step.

## 🔍 Search & Navigation

### New Unified Search
Press **⌘K** (Mac) or **Ctrl+K** (Windows/Linux) anywhere on the site to:
- Search glossary terms, articles, and documentation all at once
- Filter results by category
- Navigate using just your keyboard (arrow keys + Enter)
- See rich previews with definitions and category tags

### Improved Navigation
- **New "Docs" link** in the main menu connects you to the SORA Codex
- **YouTube icon added** to the footer for video content
- **Better mobile navigation** — the menu now works smoothly on all phones
- **Custom 404 page** helps you find what you're looking for when links break
