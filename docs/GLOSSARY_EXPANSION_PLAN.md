## Content Standards

All new terms must include:

### Required Fields

- `title` — Title Case
- `slug` — lowercase alphanumeric
- `category` — from approved list
- `summary` — 20-300 characters

### Recommended Fields

- `tagline` — "Why it matters" (10-150 chars)
- `related` — 3-5 canonical slugs
- `tags` — 2-5 relevant tags

### Quality Checklist

- [ ] Accurate and factual
- [ ] SORA-specific context included
- [ ] Related terms linked
- [ ] No passive voice in summary
- [ ] Tagline explains value proposition
- [ ] Reviewed by domain expert
