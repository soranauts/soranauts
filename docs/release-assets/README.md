# Release Assets — Screenshot Kit

This folder contains screenshots and visual assets for the Nexus Glossary V2025 release.

## Required Screenshots

Capture these screenshots before publishing release notes or blog posts:

### 1. glossary-hero.png
**Description:** The glossary homepage showing the hero section, search bar, category filters, and term cards.

**Capture instructions:**
1. Navigate to `https://soranauts.com/glossary`
2. Ensure browser is 1440px wide (desktop)
3. Capture the full hero section including:
   - Page title and subtitle
   - Search input
   - Category filter chips
   - First row of term cards
4. Save as `glossary-hero.png` (1440×900 recommended)

---

### 2. quick-view.png
**Description:** The Quick-View panel open with a term displayed.

**Capture instructions:**
1. Navigate to `https://soranauts.com/glossary?term=tokenbondingcurve`
2. Wait for panel to fully open
3. Capture showing:
   - The slide-in panel on the right
   - Category badge
   - Title and summary
   - "Why it matters" callout
   - Related terms section
   - "Go deeper" button
4. Save as `quick-view.png` (1440×900 recommended)

---

## Image Specifications

| Property | Value |
|----------|-------|
| Format | PNG (preferred) or WebP |
| Width | 1440px (desktop) or 375px (mobile) |
| DPI | 2x (retina) recommended |
| Compression | Lossless or high quality |
| Max file size | 500KB per image |

## Naming Convention

```
{feature}-{variant}.png

Examples:
- glossary-hero.png
- glossary-hero-dark.png
- glossary-hero-mobile.png
- quick-view.png
- quick-view-loading.png
```

## Tools

Recommended screenshot tools:
- **macOS:** Built-in (Cmd+Shift+4) or CleanShot X
- **Chrome:** DevTools device toolbar (Cmd+Shift+M)
- **Cross-platform:** Playwright screenshot API
