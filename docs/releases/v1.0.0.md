# v1.0.0 — Official Open-Source Launch

**Release Date:** January 15, 2026

Soranauts is now officially open source! This release marks the completion of a comprehensive SORA ecosystem content platform, featuring an interactive glossary, in-depth articles, and an AI-powered knowledge base.

---

## ✨ Highlights

### 📚 Comprehensive Glossary
- **370 terms** covering the SORA ecosystem, DeFi, and blockchain technology
- **Pagefind-powered search** with instant results
- **18 content categories**: Accounts & Identity, Consensus, Cryptography, Data Availability, DeFi, Developer Experience, Economics, Ecosystem, Execution, Governance, Network, Networking, Observability & Operations, Serialization & Encoding, Storage, Technology, Token, Use Cases
- **Auto-linking** in blog posts with hover tooltips
- **Deep linking** support for direct term access

### 📝 Content Library
- **45 articles** covering SORA ecosystem topics, DeFi strategies, and blockchain education
- **Expert analysis** of XOR, VAL, PSWAP tokens
- **Guides** for Polkaswap, Kensetsu, and SORA governance

### ⚛️ Modern Architecture
- **React Islands** — Interactive components via Astro's React integration
- **Monorepo structure** — Shared packages for chain interactions, configurations, and UI
- **RAG Knowledge Base** — ChromaDB-powered semantic search for intelligent content retrieval
- **API Endpoints** — Rate-limited endpoints for blockchain interactions

## 🚀 Getting Started

```bash
# Prerequisites
node -v  # 20.x required
pnpm -v  # 9.x required

# Clone and install
git clone https://github.com/soranauts/soranauts.git
cd soranauts
pnpm install

# Start development server
pnpm dev
# Open http://localhost:4321
```

For detailed setup instructions, see the [README](https://github.com/soranauts/soranauts#readme).
