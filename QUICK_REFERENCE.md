# Quick Reference: Article Writing Guidelines

## 🚨 Critical Rules (Never Break These)

### ❌ NEVER DO
- **Don't add H1 title in content** - Blog layout handles this
- **Don't duplicate internal links** - Check Related Articles first
- **Don't use generic anchor text** - Use descriptive, keyword-rich text
- **Don't over-link** - Max 2-3 links per major section

### ✅ ALWAYS DO
- **Match filename to title** - For SEO consistency
- **Use descriptive anchor text** - Tell users what they'll find
- **Include meta description** - 150-160 characters with keywords
- **Test all links** - Before publishing

## 📋 Article Structure (Copy This)

```markdown
---
publishDate: YYYY-MM-DDTHH:MM:SSZ
updateDate: YYYY-MM-DDTHH:MM:SSZ
title: "Main Topic: Descriptive Subtitle"
excerpt: "150-160 char description with keywords"
image: ~/assets/images/filename.jpg
category: "Category Name"
tags: ["Keyword1", "Keyword2", "Keyword3"]
---

<!-- Start with content, NO H1 title -->

[Opening paragraph that hooks readers]

## Major Section (H2)

[Content with 2-3 contextual links]

### Subsection (H3)

[Supporting content]

---

## Additional Resources

### 📚 Essential Reading
- [Internal Article](https://soranauts.com/slug) - Description

### 🔗 External Tools & Platforms  
- [Official Site](https://external.com) - What users can do

### 🌐 Community & Support
- [Community](https://community.com) - What users will find
```

## 🔗 Linking Strategy

### In-Article Links (2-3 per major section)
- **External Authority**: `[Company Name](https://official-site.com)`
- **Internal Deep-Dive**: `[Article Title](https://soranauts.com/slug)`
- **Reference**: `[Source](https://source.com)`

### Resource Section (Bottom)
- **Essential Reading**: 2-3 internal articles
- **External Tools**: 2-3 official websites
- **Community**: 2-3 support channels

## ✅ Pre-Publish Checklist

- [ ] No H1 title in content
- [ ] No duplicate links
- [ ] All links work
- [ ] Meta description 150-160 chars
- [ ] Title matches filename
- [ ] Images have alt text
- [ ] Good heading structure

## 🎯 SEO Keywords

### Title Format
"Primary Keyword: Descriptive Subtitle with Secondary Keywords"

### Meta Description
"Compelling description with primary keywords and value proposition (150-160 characters)"

### Tags
Include 5-8 relevant tags that match your content and help with Related Articles
