# BCK22 (Blockchain Kaigi 2022) Source Files

This directory contains raw source files for BCK22 proceedings.

## Usage

1. **Download files** from the BCK22 proceedings page
2. **Place files** in this directory:
   - RIS files: `*.ris`
   - PDF files: `*.pdf`
3. **Run import script**:
   ```bash
   pnpm --filter @soranauts/web kb:bck24:import --year bck22
   ```

See `knowledge_base/sources/bck24/README.md` for full documentation.
