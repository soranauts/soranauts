# Theory of EDISON-X Order Automation Using Machine Learning Approaches

## Abstract

EDISON-X is an energy trading system that uses blockchain technology to manage the buying and selling electricity usage rights. A demonstration experiment on the EDISON-X system provided feedback that the process of daily order creation is cumbersome for system users. To solve this cumbersome, we incorporate a mechanism for automating the ordering processes into the EDISON-X system to optimize electricity trading prices and increase trading volumes. This paper examines what algorithm would be suitable for achieving an effective automatic ordering algorithm in the electricity trading market using the single-price auction mechanism within the EDISON-X system. The algorithms we examined contain several objective functions for optimization and reinforcement learning. We plan to conduct a demonstration experiment to validate this automatic ordering algorithm.
