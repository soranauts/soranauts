# Centrality Evolution in Bitcoin Lightning Network: An Empirical Application of Maximize In-block Nestedness Allocation Algorithm

## Abstract

This research explores the dynamic evolution of the nested structure within the Bitcoin Lightning Network (BLN), based on centralization and network science theory. We apply the significant testing method of NODF, modularity with the in-block nestedness model with null model randomization. This method shows a noticeable growth in in-block nested structure coinciding with the network?s expansion. The maximize in-block nestedness allocation algorithm is proven to identify pivotal nodes, providing an approach for detecting important nodes within complex systems of nested structure. The study enhances our understanding of network dynamics and micro-stage structures within the BLN as centralization and unevenness rise. It provides the application of the algorithm for a significant check of micro-stage network structure, crucial node detection.
