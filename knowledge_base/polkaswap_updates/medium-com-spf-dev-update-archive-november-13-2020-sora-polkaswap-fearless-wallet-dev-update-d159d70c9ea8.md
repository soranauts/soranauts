The [SORA](https://sora.org), [Polkaswap](https://polkaswap.io), and [Fearless Wallet](https://fearlesswallet.io) projects are all closely related as they form integral parts of the SORA ecosystem. That is why we release a development status update every two weeks for these three projects, in one convenient place. Enjoy our November 13 Dev update! If you missed the previous ones, check out our [October 30th DEV update](https://sora-xor.medium.com/october-30-2020-dev-updates-for-sora-polkaswap-and-fearless-wallet-9ff465a6d751) and [October 16th DEV update](https://sora-xor.medium.com/october-16-2020-dev-updates-for-sora-polkaswap-and-fearless-wallet-71e4884e29d7).

SORA Dev Update #3
------------------

— — — — — — — — — — — — — — — — —

Press enter or click to view image in full size

✌️ The VAL token was released on the **SORA** **testnet** and available in mobile applications for iOS and Android

📱The SORA Testnet application (**Soralution)** with VAL tokens is available for [iOS](https://testflight.apple.com/join/670hF438) and [Android](https://play.google.com/store/apps/details?id=jp.co.soramitsu.sora.communitytesting) for testing. Please provide your feedback in the [Soralution telegram chat](https://t.me/sora_testnet).

💱 The Ethereum Bridge has been released and activated on the **testnet. Now you’re able to send VAL tokens to the Ethereum testnet** (Rinkeby). If you don’t have TEST VAL tokens, ask someone in the [Telegram chat](https://t.me/sora_testnet)!

💫 The redesign of the application is on the development state.

🌾 Sora farm launch is expected after VAL release on production! SORA Farm is a **community initiative** game that allows users to harvest $PSWAP tokens by providing liquidity for ETH-XOR, ETH-VAL, and XOR-VAL pairs in Uniswap or Mooniswap. Up to 2% of the PSWAP supply will be allocated for the game.

Polkaswap Dev Update #5
-----------------------

— — — — — — — — — — — — — — — — —

👉 We’ve successfully launched our public testnet backend on our rococo network. 🎉

🧑🏻‍🔧JS client library draft published in public NPM. It contains SORA-Substrate and Polkaswap APIs with our custom types.

🌾 XOR staking — Now it is possible for node operators to stake XOR to run a node on the network. XOR stake nomination (delegation) will be implemented in the future.

💫 Working on an independent substrate network with babe/grandpa consensus to be able to have a sustainable and secure network before a parachain is available.

🧑‍⚖️ Functions’ weight estimations (for network gas fees) are prepared for the initial version.

Fearless Wallet Dev Update #9
-----------------------------

— — — — — — — — — — — — — — — — —

💠 **Polkaswap integration** has started — the team prepared an initial version of mockups for swap and liquidity pool features.

🥞 **Staking** (Nominator and Validator) **features** are in the design phase, the team is working to provide the best UI/UX for staking using the mobile app.

✔️ The **export account feature** is completed — users will be available to export accounts and Restore using JSON/Mnemonic/Seed formats.

📳 **Push notifications** development in Kusama ecosystem is in progress — Fearless Wallet team is working together with the [Ryabina Validator team](https://github.com/Ryabina-io/substratebot) to improve UX for mobile apps with push notifications.

🚀 The **Android version was updated to 0.4.1** — we have delivered the “Receive” feature as well as several bug fixes; you can learn more in the changelog on the [Google Play](https://play.google.com/store/apps/details?id=jp.co.soramitsu.fearless) page.

About SORA NEO Network, Polkaswap, and Fearless
-----------------------------------------------

[SORA NEO (New Economic Order)](/@sora.xor/sora-the-new-economic-order-3ec3f0327e5a) is a new economic system aimed at creating a supranational, decentralized central bank (DCB) with built-in tools for decentralized finance (DeFi). The [SORA](https://sora.org) network implements a new way of parachain architecture on [Polkadot](https://polkadot.network/) and [Kusama](https://kusama.network/) network, with the capability to [bridge](https://wiki.polkadot.network/docs/en/learn-bridges) external blockchains (like Ethereum) to Polkadot ecosystem. One of the DeFi applications that will run on the SORA network is [Polkaswap](https://polkaswap.io/), a non custodial liquidity aggregator cross chain AMM DEX designed uniquely for the Polkadot ecosystem with boundless liquidity through one of a kind **Aggregate Liquidity Technology (ALT)** with the security and convenience of a DEX.

[Fearless Wallet](https://fearlesswallet.io/) is a mobile wallet designed for the decentralized future on the Kusama and Polkadot networks, with support for iOS and Android platforms. An awesome user experience, fast performance, and secure storage for your accounts. The Fearless wallet will integrate withPolkaswap for easy, decentralized swaps of assets.
