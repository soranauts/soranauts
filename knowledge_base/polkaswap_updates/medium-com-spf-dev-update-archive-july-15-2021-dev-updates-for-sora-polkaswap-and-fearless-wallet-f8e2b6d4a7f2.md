SORA Dev Update #17
-------------------

🎈 SORA testnet runtime upgrade was deployed. We focused on performance issues and stability 🔝

* Slow block production problems fixed
* Slow websocket and RPC performance fixed
* Fees for reward claiming was updated
* Fast native WASM runtime

💧 Working on the Polkaswap mobile app module. First results will be available in 2 weeks for Android!

🙏 Collaborations:

* Working with the [SubQuery](https://subquery.network/) team. Statistic calculations will be easier!
* Working with the [SubScan](https://www.subscan.io/) team. One more block explorer for the SORA substrate network!

🔺 The inaugural SORA Economic Forum recordings are now available

* New video released every day for the next week on [youtube.com/sora\_xor](http://youtube.com/sora_xor) and [soranomics.com](http://soranomics.com)

Polkaswap Dev Update #19

Fearless Wallet Dev Update #23
------------------------------

📍 Next demo is scheduled for the 23rd of July at 17:00 UTC+3

🎊 Next release is in the coming week, including:

* Selecting custom validators
* The first version of staking analytics with charts
* Staking improvements: countdown timers & naming improvements
* History and filters on the Wallet tab for Android

🙏 Collaborations:

* **Mobile Signers** — PoC with [**Beacon**](https://www.walletbeacon.io/)**:** first version is completed, Fearless Wallet can connect to DApps via Beacon to sign the operations. Fearless Wallet’s team provided feedback and is going to improve the solution together with the Beacon team.
* **Push Notifications** — PoC with [**Ryabina**](https://ryabina.io/)**:** Ryabina team has finished the testing environment, Fearless Wallet’s team is going to integrate push notifications solution next week.

💬 Proposals:

* [**SubQuery**](https://subquery.network/) **& Common API:** Fearless Wallet’s team is now working with SubQuery to design a common API for the Polkadot ecosystem
* **Multi-Asset Proposal to Kusama:** this week we are planning to post a proposal for discussion. Our goal is to improve Fearless Wallet’s account and network management in a way that would allow for users to have much more effortless and convenient access to all their tokens from different Substrate-based networks on one single screen!

About SORA NEO Network, Polkaswap, and Fearless Wallet
------------------------------------------------------

[**SORA**](/@sora.xor/sora-the-new-economic-order-3ec3f0327e5a) is a new economic system aimed at creating a supranational, world economic system with built-in tools for decentralized finance (DeFi). The [SORA](https://sora.org) network implements a new way of parachain architecture on [Polkadot](https://polkadot.network/) and [Kusama](https://kusama.network/) network, with the capability to [bridge](https://wiki.polkadot.network/docs/en/learn-bridges) external blockchains (like Ethereum) to the Polkadot ecosystem.

One of the DeFi applications that will run on the SORA network is [**Polkaswap**](https://polkaswap.io/), a non custodial liquidity aggregating, cross chain AMM DEX designed uniquely for the Polkadot ecosystem with boundless liquidity through its one-of-a-kind **Aggregate Liquidity Technology (ALT)**.

[**Fearless Wallet**](https://fearlesswallet.io/) is a mobile wallet designed for the decentralized future on the Kusama and Polkadot ecosystem, with support for iOS and Android platforms. An awesome user experience, fast performance, and secure storage for your accounts. Fearless Wallet will integrate Polkaswap for easy, decentralized swaps of assets.
