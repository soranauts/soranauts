The Polkaswap Testnet
---------------------

We are happy to launch the Polkaswap testnet with basic functionality! The team is working on adding new features and fixing issues as they are found. After that, a security audit will be performed.

For now you can try the following features (there are still some issues occasionally):

* swap tokens
* add liquidity
* get test tokens
* send assets

If you want to provide suggestions or issues, please send them to the telegram chat at [https://t.me/joinchat/UvXVAf5pFj86ycZK](https://t.me/joinchat/UvXVAf5pFj86ycZK).

According to the roadmap, Polkaswap will launch with basic features in Q1 of 2021 and advanced features are expected in Q2.

Getting Access to the Polkaswap Testnet
---------------------------------------

You can use the Polkaswap testnet with a desktop browser and the Polkadot-js extension installed. Currently mobile browsers are not supported. The [polkadot-js extension](https://github.com/polkadot-js/extension) is required for using the web application:

* On Chrome, install via [Chrome web store](https://chrome.google.com/webstore/detail/polkadot%7Bjs%7D-extension/mopnmbcafieddcagagdcbnhejhlodfdd)
* On Firefox, install via [Firefox add-ons](https://addons.mozilla.org/en-US/firefox/addon/polkadot-js-extension/)

Please make sure an account has been added in the polkadot-js extension:

Connect Your Account to the Polkaswap Testnet
---------------------------------------------

Go to [https://test.polkaswap.io/](https://test.polkaswap.io/) and click on the wallet icon in the top-right corner. After that you’ll be able to import your account with the polkadot-js extension. Click on **Import wallet** and select Polkadot.js (the only option) and click **Import**. Select the account that you’d like to import. After that click **Import** again.

Getting Test Tokens
-------------------

There is a testnet faucet that can be used for getting test tokens: [https://testfaucet.polkaswap.io/](https://testfaucet.polkaswap.io/). Users are able to get 100 XOR, 100 PSWAP, and 100 VAL every day to their account.

Open the faucet, select the asset, copy your address and set the amount of tokens you want. After that, click **Send testnet <asset name>** and wait. The loader will be displayed on the button. You’ll see the success message when transaction completes. If no message shows up after some time, try to refresh the page.

Using the Polkaswap Wallet Menu
-------------------------------

Go back to your [wallet](https://test.polkaswap.io/exchange/wallet) and add the token, clicking the **Add token** button. Then select the token and click **Add token** again. Now you can use this token. The token can then be sent to another address or swapped.

Polkaswapping
-------------

With Polkaswap, users are able to swap tokens! Click **swap** in the wallet or open the main exchange screen. Input the amount of tokens and select the desired “To” token. After that, confirm the **Swap** and sign it with the polkadot-js extension. Go to your wallet and add the asset that you’ve bought to see it.

Press enter or click to view image in full size

Liquidity Pool Operations
-------------------------

Go to the pool tab and you can add liquidity for a token pair. Select the asset pair and enter the amount of each asset. After that confirm adding the liquidity and sign it with polkadot-js extension. Go to your wallet and add the asset that you’ve bought. After that you can find your pool and pool tokens in the wallet. All pairs on Polkaswap must have XOR as one of the tokens.

About SORA, Polkaswap, and Fearless Wallet
------------------------------------------

[SORA NEO (New Economic Order)](/@sora.xor/sora-the-new-economic-order-3ec3f0327e5a) is a new economic system based upon a supranational, decentralized central bank (DCB) with built-in tools for decentralized finance (DeFi). The [SORA](https://sora.org/) network implements a new kind of parachain architecture on the [Polkadot](https://polkadot.network/) and [Kusama](https://kusama.network/) networks, providing the capability to [bridge](https://wiki.polkadot.network/docs/en/learn-bridges) external blockchains (like Ethereum) to the Polkadot ecosystem.

One of the DeFi applications that will run on the SORA network is [Polkaswap](https://polkaswap.io/), a non-custodial liquidity aggregator cross-chain AMM DEX designed specifically for the Polkadot ecosystem. Polkaswap combines the security and convenience of a DEX with a one-of-a-kind **Aggregate Liquidity Technology (ALT)** capable of providing boundless liquidity.

[Fearless Wallet](https://fearlesswallet.io/) is a mobile wallet designed for the decentralized future on the Kusama and Polkadot networks, with support for the iOS and Android platforms. It offers an awesome user experience, fast performance, and secure storage for your accounts. The Fearless wallet will integrate with Polkaswap for easy, decentralized asset trading.
