SORA Dev Update #18
-------------------

🏮 The **SORA mainnet runtime upgrade was prepared and will be live soon!**

* Slow block production problems were fixed
* Slow websocket and RPC performance was fixed
* Fees for rewards claiming was updated
* Fast native WASM runtime

💧 Progress was made **on the Polkaswap mobile app module**

* Swap in the mobile application is being tested now
* Working with liquidity pools is being estimated and planned

🚀 **SORA Android mobile** [**application**](https://play.google.com/store/apps/details?id=jp.co.soramitsu.sora) **version 2.2**

* available for beta users with asset details feature

* Working with the [SubQuery](https://subquery.network/) team. Statistic calculations will be easier!
* Working with the [SubScan](https://www.subscan.io/) team. One more block explorer for the SORA substrate network! [https://sora.subscan.io](https://sora.subscan.io)

Polkaswap Dev Update #20
------------------------

🎁 The Polkaswap mainnet web application was prepared and will be live soon!

* Improvements were made for the Tokens list page and whitelisting, Rewards page, and various other user interface enhancements
* [SORAScan](https://sorascan.com/sora-mainnet) links added
* HASHI bridge interaction was made more stable thanks to the [ether.js](https://docs.ethers.io/v5/) library migration

👨‍💻 New mainnet runtime upgrade was prepared and will be live soon!

* Farming rewards calculation was implemented. Previous farming rewards, since the network was launched, until the next update, will be recalculated in a future update.
* Market maker rewards calculation was added
* TBC rewards calculation was fixed

About SORA, Polkaswap, and Fearless Wallet
------------------------------------------

[**SORA**](/@sora.xor/sora-the-new-economic-order-3ec3f0327e5a) is a new economic system aimed at creating a supranational, world economic system with built-in tools for decentralized finance (DeFi). The [SORA](https://sora.org) network implements a new way of parachain architecture on [Polkadot](https://polkadot.network/) and [Kusama](https://kusama.network/) network, with the capability to [bridge](https://wiki.polkadot.network/docs/en/learn-bridges) external blockchains (like Ethereum) to the Polkadot ecosystem.

One of the DeFi applications that will run on the SORA network is [**Polkaswap**](https://polkaswap.io/), a non custodial liquidity aggregating, cross chain AMM DEX designed uniquely for the Polkadot ecosystem with boundless liquidity through its one-of-a-kind **Aggregate Liquidity Technology (ALT)**.

[**Fearless Wallet**](https://fearlesswallet.io/) is a mobile wallet designed for the decentralized future on the Kusama and Polkadot ecosystem, with support for iOS and Android platforms. An awesome user experience, fast performance, and secure storage for your accounts. Fearless Wallet will integrate Polkaswap for easy, decentralized swaps of assets.
