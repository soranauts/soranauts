Fearless Wallet Ecosystem Update #42
------------------------------------

### 🍎 iOS version

💪 [v2.0.7](https://apps.apple.com/ru/app/fearless-wallet/id1537251089?l=en) was released on April, 5th.

This build contains the following features:

✅ [Kintsugi](https://kintsugi.interlay.io/) parachain support: balances and transfers

✅ Several wallet Import refinements

✅ Minor staking and crowdloan flows update regarding the recent Runtime 9170/80 update

✅ Some architectural and UI improvements

🦾 The iOS team’s current goal is to complete the remaining features as outlined by the recent Kusama treasury grant. They are as follows:

✨ _Wallet Export feature_. **_Status: done and ready for internal testing_**.

✨ _Asset management feature_ which will allow users to show/hide any assets, drag’n’drop, and change their order. **_Status: done and ready for internal testing_**.

✨ _Add chain accounts_ with unique key pairs. **_Status: in progress_**.

### 🤖 Android version

💪 [v2.0.4](https://play.google.com/store/apps/details?id=jp.co.soramitsu.fearless) was released on March, 30th with the following set of features:

✅ Fiat currencies management — users are able to see their balances in various fiat currencies

✅ Several UI and performance improvements — implementing so-called “skeletons” and connections statuses

✅ Minor staking and crowdloan flow update — implementations regarding the recent Runtime [9170](https://polkadot.polkassembly.io/referendum/53)/[80](https://polkadot.polkassembly.io/post/966) update

✅ Some architectural and UI improvements

🦾 Current activities of the Android team:

✨ Cleaning codebase, removing technical debt, preparing for Kusama grant report

✨ Moonbeam collator staking implementation

About SORA, Polkaswap, and Fearless Wallet
------------------------------------------

[**SORA**](/@sora.xor/sora-the-new-economic-order-3ec3f0327e5a) is a new economic system aimed at creating a supranational multiverse economic system with built-in tools for decentralized finance (DeFi). The [SORA](https://sora.org/) network implements a new way of parachain architecture on [Polkadot](https://polkadot.network/) and [Kusama](https://kusama.network/) network, with the capability to [bridge](https://wiki.polkadot.network/docs/en/learn-bridges) external blockchains (like Ethereum) to the Polkadot ecosystem.

One of the DeFi applications that will run on the SORA network is [**Polkaswap**](https://polkaswap.io/), a noncustodial liquidity aggregating, cross-chain AMM DEX designed uniquely for the Polkadot ecosystem with boundless liquidity through its one-of-a-kind Aggregate Liquidity Technology (ALT).

[**Fearless Wallet**](https://fearlesswallet.io/) is a mobile wallet designed for the decentralized future on the Polkadot and Kusama ecosystem, with support for iOS and Android platforms. An awesome user experience, fast performance, and secure storage for your accounts. Fearless Wallet will integrate Polkaswap for easy, decentralized swaps of assets.
