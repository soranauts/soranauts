About SORA NEO Network, Polkaswap, and Fearless
-----------------------------------------------

[**SORA NEO (New Economic Order)**](/@sora.xor/sora-the-new-economic-order-3ec3f0327e5a) is a new world economic system aimed at creating a supranational, decentralized central bank, featuring a pre-built toolkit for decentralized finance (DeFi). SORA v2 is built on [Substrate](https://web3-technology-stack.readthedocs.io/en/latest/layer_1/protocols/substrate/) and is preparing to become a [Kusama and Polkadot parachain](/@polkaswap/sora-network-parachain-for-polkaswap-intro-859558753f48). One of the DeFi applications that will run on the SORA network is [**Polkaswap**](https://polkaswap.io/), a non-custodial AMM DEX designed uniquely for the Polkadot ecosystem with boundless liquidity enabled by groundbreaking **Liquidity Aggregation Technology (LAT)**, with the security and convenience of a DEX.

[**Fearless Wallet**](https://fearlesswallet.io/) is a mobile wallet designed for the decentralized future on the Kusama and Polkadot networks, with support for iOS and Android platforms. The wallet features an awesome user experience, fast performance, and secure storage for your accounts. The Fearless wallet will integrate Polkaswap for easy, decentralized swaps of assets.
